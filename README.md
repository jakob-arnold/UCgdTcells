# Single-cell Profiling Reveals Diverse γδ T Cell Subsets in Ulcerative Colitis

[Mayer SM, Arnold J, et al., Science Immunol. 2026](https://doi.org/10.1126/sciimmunol.adx8474)

This repository contains the code used for creating all scRNA-seq and flow cytometry plots in our manuscript. Files needed for the analysis can be downloaded from [zenodo](https://doi.org/10.5281/zenodo.17524531). This download link contains both the raw data (count matrices etc.) and the processed R objects (as .Rds files). Raw data can be used to start from step 1 (`/1_process_code`), R objects can be directly used for step 2 (`/2_figures_code`).
